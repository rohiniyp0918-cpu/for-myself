MERI JAAN — BIRTHDAY SURPRISE WEBSITE 💗
A mobile-friendly birthday surprise made with HTML, CSS and JavaScript.

WHAT HAPPENS
1. A wine-coloured welcome screen says "Click here for surprise".
2. Floating hearts, water-drop hearts and cute emojis drift around every screen.
3. Four balloons reveal, in order, Happy / Birthday / Meri / Jaan with a typing effect.
4. After all four are popped, a big birthday blast appears.
5. "Click for your gift" opens the cake.
6. Blowing out the cake candles reveals your singing video.

ADD YOUR SINGING VIDEO
1. Put your video file inside the media folder.
2. Rename it exactly: my-singing-video.mp4
3. The video is already connected in index.html.
4. If your video has another format, update the <source> type and filename in index.html.
   MP4 (H.264 video + AAC audio) is the most widely compatible choice.
5. Keep the video reasonably compressed so it loads quickly on mobile data.

RUN ON WINDOWS
1. Extract meri-jaan-birthday.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in a browser.
4. Or open the folder in Visual Studio Code and use the Live Server extension.

PUBLISH AND SHARE A LINK
1. Open https://app.netlify.com/drop
2. Sign in if asked.
3. Drag the extracted project folder (the folder containing index.html, style.css, script.js and media) into the upload area.
4. Follow the site's instructions and copy the published URL.
5. Test the link on your phone before sending it.

CUSTOMIZE
- Edit the text in index.html for your own words.
- Change colours near the top of style.css in the :root section.
- Keep index.html, style.css, script.js and media in their current relative locations.
- No database, framework, or build process is required.

NOTE
The project includes no personal video, photos, or music. Add your own singing video before publishing.
The floating emoji placement uses JavaScript random positions and may vary on each page load.
